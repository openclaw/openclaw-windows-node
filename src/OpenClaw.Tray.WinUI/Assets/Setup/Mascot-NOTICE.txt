Windows adaptation:
- Native retained WinUI vector shapes, without SwiftUI or raster substitutes.
- All nine moods, sixteen gesture clips, seeded randomized micro-behaviors,
  pointer gaze, tap reactions, idle sleep, nightcap and graduation cap are ported.
- xorshift64* matches the upstream generator; floating-point range conversion
  and bounded tap selection use C# sampling, not Swift's standard-library mapping.
- A native CompositionVisualSurface captures the actual retained artwork for
  the static theme-specific silhouette DropShadow. No duplicate art or raster.
- Windows animation preferences select static mood poses; hidden and unloaded
  controls stop their timer. A 24-unit gutter contains the animated 120-unit art.
  The Windows 182-DIP layout frame scales 168 canvas units to 130 DIPs of art.
  This reserves overflow rather than using Mac's 145-point frame with overflow.
- Sleep-effect letters use the Windows native text font rather than Mac typography.
- Artwork preserves the upstream light/dark brand palette. High contrast uses
  the user's system colors. No SF Symbols were imported.
