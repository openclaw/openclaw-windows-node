# Changelog

## Unreleased

- CI: batch main CodeQL scans every six hours while preserving PR, master, tag, and manual scans; include attribute-only changes in PR and master scanning, and restore fork PR scans by retiring the completed setup-migration gate.
- Add `--headless-setup [--config <file>] [--force-setup] [--replace-existing]` to the tray executable and `-SetupConfig`/`-ForceSetup`/`-ReplaceExisting` to `run-app-local.ps1`, which run WSL gateway setup from a config file without UI and then launch the tray. Setup is skipped when the data directory is already configured, and replacing an existing app-owned distro or local gateway requires `--replace-existing`. A distro or its data not proven to be managed by OpenClaw is never replaced headlessly; the refusal points to interactive setup or manual removal. Headless setup is refused in the packaged app, and a completed or uncheckable Store migration is reported on stderr instead of in a dialog. Setup runs from different data directories now share a lock on the local setup data, so concurrent profiles cannot replace each other's distro.
- Select a compatible managed Local AI runtime/model profile and explain hardware fallbacks. Add an experimental, pinned Bonsai 2 27B PTQ1_0 profile for Windows x64 NVIDIA GPUs with 8 GiB VRAM, 16 GiB system RAM, and 16 GiB free on a shared runtime/model-cache volume (8 GiB each when separate). Disk shortages can be rechecked after freeing space. Thanks @alexandre-leng.
